# Calculadora Java

Calculadora de linha de comando desenvolvida em Java, com menu interativo que permite ao usuário escolher entre quatro operações matemáticas básicas.

Fiz esse projeto pra praticar lógica de programação e a sintaxe do Java, traduzindo uma versão que eu já tinha feito antes em Python.

## Funcionalidades

- Soma, subtração, multiplicação e divisão
- Menu em loop, permitindo múltiplos cálculos sem reiniciar o programa
- Encerramento controlado pelo usuário (o programa pergunta se ele quer continuar após cada cálculo)

## Como executar

```bash
javac calculadora.java
java calculadora
```

## Exemplo de uso

```
=====CALCULADORA=====
Digite 1 para somar
Digite 2 para subtrair
Digite 3 para multiplicar
Digite 4 para dividir
Qual vai ser a operacao? 1
Digite o primeiro numero: 10
Digite o segundo numero: 5
15.0
Deseja continuar? [S/N] N
Calculadora Finalizada!
```
